# 📸 Фотокамера

**PWA-камера для iPhone: снимает и сама отправляет фото в Supabase**

![PWA](https://img.shields.io/badge/PWA-standalone-5b4ff0?style=for-the-badge)
![iOS](https://img.shields.io/badge/iOS-16.4%2B-000000?style=for-the-badge&logo=apple&logoColor=white)
![Supabase](https://img.shields.io/badge/Supabase-Storage-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)
![No build](https://img.shields.io/badge/no%20build-HTML%20%2B%20JS-f7df1e?style=for-the-badge&logo=javascript&logoColor=black)

</div>

Веб-приложение, которое устанавливается на экран «Домой» iPhone и работает как обычная камера:
открыл — сразу видишь кадр, нажал кнопку (на экране или Bluetooth-кнопку) — снимок **автоматически**
уходит в ваш Supabase. Без диалогов, без «куда сохранить», без подтверждений.

> **⚠️ Это шаблон, а не готовый сервис.**
> В файлах **нет** проекта Supabase, ключей и аккаунта — и не подразумевается.
> Это «конструктор»: каждый создаёт **свой** проект, свой bucket, своего пользователя
> и свои политики, а затем вписывает свои значения в `config.js`.
>
> Поэтому при первом запуске приложение просит email и пароль — это вход в **ваш собственный**
> аккаунт Supabase, созданный на шаге «Своя копия». Готового аккаунта в комплекте нет —
> без своего проекта приложению просто некуда отправлять фото.

## ✨ Возможности

| Возможность | Как это выглядит |
|---|---|
| 📷 **Камера сразу** | при запуске — живой предпросмотр во весь экран, без кнопки «включить» |
| ⚪ **Кнопка съёмки** | круглая кнопка внизу, как в штатной камере |
| ⌨️ **Bluetooth-кнопка** | любая клавиша HID-клавиатуры: Enter, пробел, стрелка, буква |
| 🔁 **1 нажатие = 1 фото** | удержание и модификаторы (Shift, Ctrl…) игнорируются |
| ☁️ **Автозагрузка** | снимок сразу уходит в Storage — без диалогов и подтверждений |
| 🔢 **Счётчик сессии** | «Фото: N» сверху, сбрасывается при перезагрузке |
| 📦 **Очередь** | нет сети — снимок ждёт в IndexedDB и досылается сам |
| 🖼 **Лента** | открывается только по тапу на иконку, живёт отдельным экраном |
| 🔐 **Вход** | email + пароль (Supabase Auth), сессия запоминается на устройстве |
| 💡 **Экран не гаснет** | Screen Wake Lock + автопродление каждые 5 минут |
| 🩺 **Самодиагностика** | статус подскажет: «bucket не найден», «нет прав», «нет сети» |
| 🔇 **Без звука** | никаких сигналов и вибрации — не мешает долгой съёмке |

## 📱 Устройства

| Устройство | Браузер | Что работает |
|---|---|---|
| 🍎 **iPhone / iPad** · iOS 16.4+ | Safari | камера, съёмка, вход, «На экран „Домой"», Wake Lock, Bluetooth-клавиатура |
| 🤖 **Android** | Chrome | камера, съёмка, вход, установка PWA, Bluetooth-клавиатура |
| 💻 **Компьютер** | Chrome / Edge / Safari | камера и съёмка (в Chrome/Edge можно установить как приложение) |

> **Обязательные условия**
>
> - **HTTPS** — без него браузер не откроет камеру (исключение: `localhost`).
> - **Разрешение на камеру** — спрашивается один раз при первом запуске.
> - **Bluetooth-кнопка** должна притворяться HID-клавиатурой и слать клавишу.
>   Кнопки «громкость +/−» iPhone веб-странице **не отдаёт** — это ограничение iOS.

## ⚙️ Как работает

### Файлы

| Файл | Назначение |
|---|---|
| `index.html` | интерфейс: камера, кнопка, счётчик, лента, экран входа |
| `app.js` | вся логика (ES-модуль) |
| `config.js` | настройки проекта Supabase |
| `manifest.webmanifest` | описание PWA: имя, иконки, цвета |
| `sw.js` | service worker: сеть → кэш, чтобы приложение открывалось при сбое сети |
| `icon-180.png`, `icon-512.png` | иконки приложения |

### Поток данных

1. **Загрузка** → регистрируется service worker → проверяется сессия Supabase Auth.
2. **Сессии нет** → экран входа: email + пароль (или регистрация).
3. **Сессия есть** → `getUserMedia` (задняя камера, до 1920×1440) → `<video>`.
4. **Снимок** (кнопка или клавиша) → кадр в `<canvas>` → `toBlob('image/jpeg', 0.82)`,
   ширина ограничена **1600 px** (≈200–400 КБ на файл).
5. **Blob → очередь** IndexedDB → фоновый `drain()` загружает его в Storage.
6. **Ошибка сети** → файл остаётся в очереди, повтор каждые **8 секунд**.
7. **Лента** → `list()` своей папки → `createSignedUrl(…, 600)` → миниатюры на **10 минут**.
8. **Wake Lock** запрашивается при старте и продлевается каждые **5 минут**;
   при возврате на страницу камера переподключается сама.

### Где что менять

| Что | Функция / место |
|---|---|
| Включение камеры | `startCamera()` |
| Снимок и качество JPEG | `capture()` — `1600` px, `0.82` |
| Имя файла | `makeName()` |
| Загрузка и очередь | `drain()`, `queueAdd()` |
| Триггер с клавиатуры | обработчик `keydown` |
| Лента | `openGallery()` |
| Вход | `signInWithPassword` / `signUp` |
| Блокировка сна | `requestWake()` |

## 📤 Куда уходят файлы

```text
Supabase Storage
└── photos/                     ← bucket (приватный)
    └── <uid-пользователя>/     ← папка каждого пользователя
        └── shot-20260101-120000-123-4567.jpg
```

| Свойство | Значение |
|---|---|
| Хранилище | Supabase Storage, bucket `photos` |
| Путь | `<uid>/shot-ГГГГММДД-ЧЧММСС-ммм-рандом.jpg` |
| Доступ к bucket | приватный, публичных ссылок нет |
| Просмотр | подписанные ссылки, живут **10 минут** |
| Кто читает | только вошедший пользователь, только своя папка (RLS) |
| Удаление / перезапись | **невозможны** — политик на delete/update нет |

Направить всё можно в **любой свой проект Supabase** (в том числе self-hosted) —
достаточно поменять `config.js` и повторить политики.

## 🧰 Своя копия за 10 минут

### 1 · Проект Supabase

- Регистрация на [supabase.com](https://supabase.com) → **New project** (план Free).
- Записать **Project URL** и **publishable/anon key**: *Settings → API*.

### 2 · Bucket

- *Storage → New bucket* → имя **`photos`** → **Public bucket выключен** → Create.

### 3 · Пользователь

- *Authentication → Users → **Add user*** → email + пароль, галка **Auto Confirm User**.

> **Готового аккаунта в комплекте нет.** Этот шаг обязателен: приложение всегда просит
> email и пароль, и войти можно только в аккаунт, созданный в **вашем** проекте.
> Альтернатива — включить регистрацию и зарегистрироваться прямо в приложении
> (но тогда может потребоваться подтверждение почты).

### 4 · Политики

- *SQL Editor* → выполнить скрипт из раздела **[Политики SQL](#-политики-sql)**.

### 5 · Настройки приложения

- Отредактировать [`config.js`](#-настройки-configjs) — URL, ключ, bucket.

### 6 · Публикация

Любой бесплатный статический хостинг с HTTPS:

| Хостинг | Как |
|---|---|
| **GitHub Pages** | репозиторий → *Settings → Pages → Deploy from a branch → main / root* |
| **Netlify Drop** | перетащить папку на [app.netlify.com/drop](https://app.netlify.com/drop) |
| **Vercel** | импорт папки или репозитория |

### 7 · Телефон

Safari → адрес сайта → «Разрешить» камеру → **«Поделиться → На экран „Домой"»** → войти → снимать.

## 🔧 Настройки `config.js`

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://ВАШ-ПРОЕКТ.supabase.co",
  SUPABASE_KEY: "sb_publishable_...",   // публичный ключ, НЕ service_role!
  SUPABASE_BUCKET: "photos",
  USE_UID_FOLDERS: true
};
```

| Параметр | Значение |
|---|---|
| `SUPABASE_URL` | адрес проекта Supabase |
| `SUPABASE_KEY` | **публичный** (publishable/anon) ключ. Лежит в коде сайта — это нормально: доступ ограничивают правила RLS |
| `SUPABASE_BUCKET` | имя bucket в Storage (регистр важен) |
| `USE_UID_FOLDERS` | `true` — каждый пишет в свою папку (**рекомендуется**). `false` — всё в корень bucket (проще, но небезопасно) |

> **⚠️ Никогда не вставляйте в `config.js` ключ `service_role` / `secret`** —
> он даёт полный доступ ко всему проекту и не должен попадать в публичный код.

## 🔒 Политики SQL

Закрытый вариант: чтение и запись — только вошедшему и только в свою папку.

```sql
-- убрать открытые политики, если они были
drop policy if exists "upload photos" on storage.objects;
drop policy if exists "read photos"   on storage.objects;
drop policy if exists "anon upload"   on storage.objects;
drop policy if exists "anon read"     on storage.objects;

create policy "own upload"
on storage.objects for insert
to authenticated
with check (
  bucket_id = 'photos'
  and (storage.foldername(name))[1] = auth.uid()::text
);

create policy "own read"
on storage.objects for select
to authenticated
using (
  bucket_id = 'photos'
  and (storage.foldername(name))[1] = auth.uid()::text
);
```

Проверка:

```sql
select policyname, cmd, roles
from pg_policies
where schemaname = 'storage' and tablename = 'objects';
```

Политик `delete` / `update` нет — файлы нельзя удалить или перезаписать через API.

<details>
<summary><b>Вариант «без входа» — только для экспериментов</b></summary>

Открывает bucket анонимам. **Не для личных фото:** любой, кто знает ключ из кода,
сможет заливать и читать файлы.

```sql
create policy "anon upload" on storage.objects for insert
to anon with check (bucket_id = 'photos');

create policy "anon read" on storage.objects for select
to anon using (bucket_id = 'photos');
```

При этом варианте поставьте `USE_UID_FOLDERS: false`.

</details>

## 🧩 Как менять код

| Хочу | Где менять |
|---|---|
| Качество и размер снимка | `capture()` — `1600` (ширина) и `0.82` (JPEG) |
| Имена файлов | `makeName()` |
| Какие клавиши делают фото | обработчик `keydown` (сейчас — любая, кроме `MODIFIERS`) |
| Частота повтора очереди | `setInterval(() => drain(), 8000)` |
| Срок жизни ссылок | `createSignedUrl(…, 600)` — секунды |
| Сколько фото в ленте | `list(prefix, { limit: 100 })` |
| Имя, иконки, цвет | `manifest.webmanifest`, `<meta>` в `index.html` |
| Звук / вибрация | WebAudio и `navigator.vibrate` (на iOS вибрация недоступна) |

Сборка не нужна: чистые HTML/CSS/JS, Supabase подключается с CDN
(`@supabase/supabase-js@2`). Меняете файлы — обновляете хостинг.

## ⚠️ Ограничения

| Ограничение | Детали |
|---|---|
| 🔇 Вибрация | iOS не даёт веб-странице вибрацию (`navigator.vibrate` не работает) |
| 😴 Фон | PWA «засыпает», когда свёрнуто: работает, пока открыто на экране |
| 🔒 HTTPS | камера открывается только на защищённом адресе |
| 🔄 Счётчик | сбрасывается при перезагрузке — это счётчик «за сессию» |
| 📦 Очередь | привязана к устройству и браузеру (IndexedDB) |
| 💾 Квота | бесплатный Supabase: 1 ГБ хранилища, «сон» после ~недели простоя |
| 📱 Автоблокировка | для долгих съёмок выключите: *Настройки → Экран и яркость → Никогда* |
| 🖼 «Сохранить в Фото» | в этой версии нет — снимки живут в Supabase и в ленте приложения |

## 🛡 Безопасность

- Публичный ключ (`publishable` / `anon`) **не секрет** — он по задумке лежит в коде.
  Защита строится на правилах RLS, а не на скрытности ключа.
- С закрытыми политиками ключ сам по себе **не даёт ничего**: список пуст,
  загрузка и скачивание — отказ.
- **Никогда** не кладите `service_role` в клиентский код.
- После создания своего аккаунта **выключите регистрацию**:
  *Authentication → Providers → Email → Allow new users to sign up → OFF*.
- Ключ можно перевыпустить: *Settings → API → Rotate*. Но новый снова окажется в `config.js`.
